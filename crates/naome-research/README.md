# NAOME research prototype

Standalone participant-local Rust experiment. Current consensus, ledger and runtime selection are unchanged.

Usage: [canonical operator Page](https://chatgpt.com/space/page_8428127cf0ac819196ed5dfc2ccdbbac). Experimental rules and evidence: [work record](https://chatgpt.com/space/page_f184b114501c8191891c268b0b4e9bbe).

Run `cargo run -p naome-research -- demo /absolute/fresh/directory` for the offline multi-participant scenario. Run the binary without arguments for the bounded provider and replay entrypoints.
