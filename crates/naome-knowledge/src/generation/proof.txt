## Native proof examples

This dependency-free source proves the exact closed target. Generalization proceeds inside-out to preserve the ordered binders.

<!-- nao-example: proof -->
```nao
goal=all([x,y,s],imp(eq(x,y),imp(mem(x,s),mem(y,s))))
proof:
  p0=subst(x,y,mem(x,s))
  p1=gen(p0,s)
  p2=gen(p1,y)
  p3=gen(p2,x)
  return p3
```

The following parseable source is mathematically rejected: `refl(x)` does not establish `mem(x,x)`.

<!-- nao-rejection: proof -->
```nao
goal=all(x,mem(x,x))
proof:
  p0=refl(x)
  p1=gen(p0,x)
  return p1
```

This source is rejected because `mp` needs an exact premise and an implication, in that order; neither argument is an implication here.

<!-- nao-rejection: proof -->
```nao
goal=all(x,eq(x,x))
proof:
  p0=refl(x)
  p1=mp(p0,p0)
  p2=gen(p1,x)
  return p2
```
