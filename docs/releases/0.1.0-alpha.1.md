# v0.1.0-alpha.1

This is the first versioned alpha of the economy-free NAOME knowledge node.
It provides mathematical proof, definition and question checking and authoring,
checked proof exchange, automatic peer discovery, and supervised autonomous
computation. Computation pauses and resumes under host resource pressure while
the node retains network and lifecycle control.

## Downloads and verification

- Linux x86_64: a static musl executable, built and smoke-tested on Ubuntu 24.04.
- macOS ARM64: an Apple Silicon executable for macOS 13 or later, built and
  smoke-tested on macOS 15.

Each package contains the ordinary `naome` executable, license notices, a
CycloneDX SBOM, the dependency lockfile, build identity, and installation
instructions. The release also includes checksums, the exact RustSec audit,
source and qualification metadata, and signed GitHub Actions provenance.
Follow the linked download-verification instructions before executing a binary.
No developer tools, trained models, private configuration or existing node state
are bundled.

Publication requires successful main-push CI and the complete Linux/macOS Cargo
matrix in both test and release profiles for the exact source commit. Package
checks additionally exercise the extracted binaries. These checks qualify the
recorded source and downloads; they do not establish physical multi-host,
public-network scale, or sustained production-workload performance.

## Data and upgrades

This alpha supports the current proof catalog and node configuration formats.
There is no migration from retired formats. Stop an existing node and back up
its entire data directory before replacing its executable. Use a separate
`NAOME_NODE_DIR` for an isolated trial; restore the matching backup when
reverting across data-format changes. Installation does not start the node,
and there is no automatic updater.

## Known limitations

- This is pre-release software. Protocols and stored formats may change before
  a stable release; the alpha does not promise production workload readiness.
- The macOS executable is ad-hoc signed, without Apple Developer ID signing
  or notarization. Browser downloads remain subject to Gatekeeper policy.
- Resource budgets and automatic pauses depend on host observations. A running
  node can report paused computation; status includes the reason.
- Dependency security evidence is a point-in-time whole-lockfile audit. The
  retained report includes an unmaintained-package notice for `paste`
  (RUSTSEC-2024-0436); it is not a known-vulnerability or unsoundness finding.
- Trained-model quality, physical NAT traversal and Internet-scale convergence
  are not qualified by this release.
